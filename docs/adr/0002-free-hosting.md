# Host on Render and Neon

Use a Render Static Site for the React frontend, a Render Web Service for Spring Boot, and Neon for PostgreSQL and private Object Storage. The user replaced Vercel with Render to keep application hosting on one platform. Test the Java S3 integration and frontend-to-API routing during the first deployment. Render's free-service sleep and initial cold start are accepted for the assessment and will be explained in the README and evaluator handoff. Persistent uploads must not rely on Render's local filesystem.
